# Мария Токтуева — портфолио

Сайт: https://toktuevamaria.github.io

Статический сайт без сборки: HTML, CSS и JavaScript. Любое изменение, загруженное в ветку `main`, через минуту появляется на сайте (GitHub Pages).

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы, метаданные для поиска и превью ссылок |
| `styles.css` | все стили: шрифты, сетка, отступы |
| `data/projects.js` | **все проекты**: названия, тексты, роли, раскладка картинок |
| `data/layout.js` | порядок проектов на главной и в фильтрах |
| `data/about.js` | био, текст «Обо мне», контакты, инструменты |
| `app.js` | логика сайта — обычно менять не нужно |
| `img/<проект>/` | картинки и видео проектов |
| `fonts/` | Inter Tight и EB Garamond Italic |
| `Toktueva_CV.pdf` | резюме для кнопки «Скачать CV» |

## Как добавить проект

1. Положите картинки в новую папку `img/<название>/` (ширина до 2400 px, jpg).
2. В `data/projects.js` скопируйте любой похожий проект, поменяйте `id`, тексты, `dir`, `cover` и список картинок в `comp`.
3. Добавьте `id` проекта в нужную колонку в `data/layout.js`.

## Как посмотреть сайт у себя

Откройте папку в терминале и запустите `python3 -m http.server`, затем откройте http://localhost:8000.
